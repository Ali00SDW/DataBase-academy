الجانب العملي

طبّق مفاهيم قواعد البيانات من خلال أمثلة SQL متدرجة وجداول توضيحية وتمارين عملية.

مختبر SQL العملي

شاهد المثال، افهم الاستعلام، ثم جرّب كتابة استعلام مشابه

1. إنشاء جدول الطلاب

نبدأ بإنشاء جدول لتخزين بيانات الطلاب، مع تحديد نوع كل عمود والمفتاح الأساسي. 

CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(100),
  age INT,
  city VARCHAR(50)
);

2. إدخال بيانات

نستخدم INSERT لإضافة سجل جديد إلى الجدول.

INSERT INTO students
(id, name, age, city)
VALUES
(1, 'أحمد', 21, 'دمشق');

3. استرجاع البيانات

يعرض الاستعلام التالي الطلاب الذين تزيد أعمارهم عن 18 عاماً.

SELECT *
FROM students
WHERE age > 18;
النجمة * تعني اختيار جميع الأعمدة. أما WHERE فتحدد الشرط الذي يجب أن يحققه السجل.

4. شكل البيانات

مثال توضيحي على سجلات جدول الطلاب بعد إدخال بعض البيانات.

id name age city
1 أحمد 21 دمشق
2 سارة 19 حلب
3 ليان 17 حمص

✦ جرّب بنفسك

اكتب استعلام SQL يعرض أسماء الطلاب وأعمارهم فقط، للطلاب الذين أعمارهم 20 سنة أو أكثر. 

-- اكتب حلك هنا
SELECT ______, ______
FROM students
WHERE ______;

هذا المختبر يعرض أمثلة تعليمية ثابتة. تشغيل الاستعلامات فعلياً يتطلب ربط الموقع لاحقاً بقاعدة بيانات أو بيئة SQL.
